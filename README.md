# نظام تسجيل الطلاب - Telegram Bot

## 🚀 النشر على Render

1. **انشاء حساب على [Render](https://render.com)**
2. **ربط GitHub repository**
3. **إعداد Environment Variables:**
   - `MONGO_URI`: رابط MongoDB Atlas
   - `BOT_TOKEN`: توكن بوت تيليجرام
   - `ADMIN_CHAT_ID`: رقم دردشة المدير
   - `PORT`: 3000 (تلقائي)

## 📊 MongoDB Atlas

1. انشاء حساب على [MongoDB Atlas](https://www.mongodb.com/atlas)
2. إنشاء cluster جديد
3. الحصول على connection string
4. إضافة IP إلى whitelist

## 🌐 GitHub Pages

1. رفع ملف `index.html` إلى repository
2. تفعيل GitHub Pages من الإعدادات
3. الوصول للرابط: `https://username.github.io/repo-name`

## 🔗 الروابط

- **Backend:** `https://your-app.onrender.com`
- **Frontend:** `https://username.github.io/student-registration`
- **Bot:** `t.me/your_bot_username`
